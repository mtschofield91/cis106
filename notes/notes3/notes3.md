# Notes 3

## What is a graphical user interface (GUI)?

A GUI is a graphical interface that makes it easier for humans to interact with a computer system.

## What is a desktop evironment?

Is a software bundle that provides a fully set up GUI to the user.

## What is a command line interface (CLI)?

A command line interface is the opposite of a GUI, and enables the user to interface with a computer system through entered text-based commands.

## What is a virtual console?

A virtual Console is what you use to run and manage a VM.

## What is a terminal emulator?

A program that lets you interact with an OS through text based commands.

## What is Bash?

A CLI shell and scripting language used for Unix or Unix-like OS's.

## What is a shell prompt?

A shell prompt is a customizable place to enter text based commands to a computer system.

* Clear - Clears the terminal window of previous commands.

* Echo - A print command for the terminal, used to display strings.

* date - a command to display the system date and time.

* free - a command to check free space in memory.

* uname - a command to display system information

* history - a command to display the shell history.

* man - the command to display the manual for various other commands.

* tldr - a command to display simplified manuals

* hostname - displays the version of DE being utilized.

* df - displays a specific files size

* du - is the command to display disk usage

* figlet - is a command to display entered text as ASCII art.
