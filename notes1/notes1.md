# What is Markdown?

1) **Markdown** is a *markup language*, used to write formatted text with a plain text editor. It uses simple grammatical symbols to interpret formating, making code easy to read.

# What is Git?

2) **Git** *is an open source version control system designed to track changes during software development*. It saves branching versions rather then duplicating files, as well as storing backups of current and previous versions. **Git** will allow approved users to access your code and files, implement a fork, and create their own versions or variations. These changes can be tied back into the orginal code, or kept seperate as standalone versions.

# What is Github?

3) **GitHub** functions as a *hub* for Git. It is a server with a more streamlined interface then working purely through the Git command line, allowing users to interface with Git in a more streamlined enviornment.

# What is Slack?

4) **Slack** is a communication and organization application that allows users to perform several organizational needs all within private servers. It functions much like *Discord* , but for the more corporate user base. Uses include:
  * Communication
  * File Sharing
  * Meeting Hosting
